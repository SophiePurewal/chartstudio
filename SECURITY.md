# Security Policy

## Supported version

Security fixes are applied to the latest code on the `main` branch.

## Reporting a vulnerability

Please do not publish sensitive security details, secrets, or exploit instructions in a public issue.

If GitHub's **Report a vulnerability** option is available for this repository, use it to report the issue privately. Otherwise, contact the repository owner privately through GitHub before sharing details publicly.

Include the affected area, reproduction conditions, impact, and any suggested mitigation if known.

## Scope

ChartStudio is a Figma plugin and browser-based development preview. Reports involving unsafe handling of chart data, plugin message boundaries, generated SVG/content, dependency vulnerabilities, or release artifacts are particularly useful.
